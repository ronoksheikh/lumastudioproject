# Lumademy Brand Kit

Blue visual identity built around the supplied Lumademy shell/fan mark.

Start with `02_Social/Facebook/Lumademy_Facebook_Cover_Blue.png` and `Lumademy_Facebook_Profile_Blue.png`.

Need a logo for a website? Use SVG from `01_Logos/SVG`: `Lumademy_Primary_Blue.svg` on white and `Lumademy_All_White.svg` on a dark/blue background. PNG copies are also included.

For detailed colors and logo usage see `03_Colors_and_Guidelines/Brand_Guidelines.md`.
