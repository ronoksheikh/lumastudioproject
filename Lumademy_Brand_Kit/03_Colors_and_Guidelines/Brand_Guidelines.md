# Lumademy — Brand Guidelines

## Identity
A refined version of Lumademy's existing shell/fan emblem, paired with an outlined Inter Display Medium wordmark. The symbol's geometry comes from the original logo; only the color system and layouts are new.

## Colors
| Token | HEX | Usage |
|---|---|---|
| Lumademy Blue | `#2970EC` | Primary brand blue |
| Sky Blue | `#5DAEFF` | Light end of brand gradient |
| Royal Blue | `#1557D1` | Gradient mid/deep |
| Deep Blue | `#07358F` | Gradient dark end |
| Navy | `#10234B` | Text on white |
| Night | `#071738` | Dark layouts |
| White | `#FFFFFF` | Text / reversed marks |
| Off White | `#EFF5FF` | Background |

Primary background gradient: `linear-gradient(135deg, #5DAEFF 0%, #2970EC 37%, #1557D1 72%, #07358F 100%)`
Icon gradient: `linear-gradient(135deg, #70BFFF 0%, #378AF4 42%, #1552C5 100%)`

## Typography
Use **Inter Display Medium** for the brand name and Inter / Inter Display for headings and UI. Wordmarks in this kit are converted to outlines so no font installation is needed to display the logo. Font files are not included.

## Usage
- Light background: use `Lumademy_Primary_Blue` or `Lumademy_All_Navy`.
- Blue/dark background: use `Lumademy_All_White`.
- Dark, restrained presentation: use `Lumademy_Gradient_White`.
- Small UI placements: use the symbol-only icon.
- Always keep a clear space around the symbol of roughly 1/4 of its width.
- Do not stretch, rotate, add harsh shadows, or recolor with orange.
- Social profile images keep the symbol centered within the circular crop.

## Files
- `01_Logos/SVG`: resolution-independent scalable logo variants with outlined lettering.
- `01_Logos/PNG`: transparent high-resolution exports.
- `02_Social/Facebook`: 2048px profile designs and 1640×624px covers plus 820×312px exports.
- `02_Social/Other`: square, story, widescreen and social share artwork.
- `04_Website`: SVG/PNG favicon and app icon.

This brand kit uses the blue direction requested; no peach/orange assets are used.
