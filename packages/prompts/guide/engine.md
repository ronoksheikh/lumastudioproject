# Engine — how a Luma video is built

Read this before you create the first scene of a project. It is the contract between your files and the engine.

## 1. Who owns what

A project starts **empty**. Luma Studio provides the engine read-only (the same for every project); you write
only the project's own files.

```
YOU WRITE (in the project folder)               THE ENGINE PROVIDES (read-only, never copy it)
project.json   { title, aspect, fps, tail, features? }   public/index.html   stage, layers, import map
brand.json     colours, fonts, logo paths              public/js/main.js    clock, playback, export hooks
script.json    voice settings + segments (you create)  public/js/world.js   WebGL background, particles, 3D logo
public/js/scenes/index.js   the scene list             public/js/sfx.js     synthesized sound effects
public/js/scenes/NN-name.js one file per segment       public/js/lib/       core.js, timeline.js, icons.js, recipes/
public/css/scenes.css       your scene styles          public/css/          fonts.css, base.css, recipes.css
public/audio/   voiceover.mp3 + timing.json (generated by generate_voice — never edit by hand)
assets/         uploads/ (student files), your images  assets/             fonts, Lumademy logos, world-map.json
```

- In the browser the two are merged: a scene at `public/js/scenes/02-map.js` imports `../lib/core.js`, which the
  engine serves. Use **relative URLs** only (`assets/logo.svg`, never `/assets/logo.svg`).
- Read any engine or example file with `read_guide` and its path, e.g. `read_guide({topic:"public/js/lib/recipes/counter.js"})`.
  In bash the engine is at `$LUMA_ENGINE` (read-only).
- If you truly must change an engine file for one video (e.g. add an import map entry to `index.html` after
  `npm install <pkg>`), copy it into the project at the same path (`cp "$LUMA_ENGINE/public/index.html" public/`)
  and edit the copy — the project's copy wins. Do this rarely.

Commands (bash, in the project folder): `npm run check` (static checks; `npm run check -- --page` also builds the
page in Chrome), `npm run map -- --highlight 050 --city 90.41,23.81` (writes `assets/world-map.json` for another
country; ISO numeric ids), `npm run example <starter|explainer>` (replaces the project's scenes/script/audio with a
bundled example — only when the student asks for it).

## 2. The five rules

1. **Everything is a function of time `t`.** One paused GSAP master timeline (`ctx.tl`) is sought to `t` every
   frame, then `onFrame(t)` hooks run, then WebGL renders. Never use `setTimeout`, `setInterval`,
   `requestAnimationFrame`, `Date.now()`, `Math.random()` (use `rand(i, k)`), or CSS `animation`/`transition`.
   `npm run check` rejects them.
2. **Every beat lands on a word — or on the timeline when there is no voice.** With a voice: `ctx.w('seg', i)` =
   start time (s) of word `i` of segment `seg` (negative `i` counts from the end), `ctx.wEnd('seg', i)` = its end;
   plan against the real times `generate_voice` returned. Without a voice (logo stings, music-only, silent reels):
   `project.json` `"timeline": [{ "id": "intro", "duration": 3 }, …]` gives the scenes back to back, and
   `ctx.at('intro', 1.2)` = 1.2 s into `intro`. See `read_guide("sound")` and `read_guide("logo")`.
3. **Scene = segment.** `ctx.range('seg')` → `[start, end]` (end = next segment's start, or the video end).
4. **Layer stack** inside the stage (1920×1080, or 1080×1920 for 9:16): WebGL canvas (brand gradient background,
   particles, 3D logo) → `#scenes` (your DOM) → `#fx` (flash, grain, vignette) → captions.
5. **GSAP owns transforms.** Initial states go in `fromTo`, not in CSS `transform`. One `from/fromTo` per property
   per element (the entrance); exits use `to`. Shared objects (camera, uniforms) start from a `tl.set(…, 0)`.

## 3. The files you create

**script.json** (write it with write_file before generate_voice):
```json
{
  "voice": { "voice_id": "<from list_voices>", "model_id": "eleven_multilingual_v2", "language_code": "en",
             "voice_settings": { "stability": 0.5, "similarity_boost": 0.8, "style": 0.2, "use_speaker_boost": true, "speed": 1.1 },
             "tempo": 1 },
  "segments": [ { "id": "hook", "text": "…what the voice says…" }, { "id": "cta", "text": "…" } ]
}
```
Segment ids match `[A-Za-z0-9_-]+`; one segment per scene. See `read_guide("voice")`.

**public/js/scenes/index.js** — the scene list (order = playback order):
```js
import { makeContext } from '../lib/timeline.js';
import hook from './00-hook.js';
import cta from './01-cta.js';

const SCENES = [hook, cta];

export async function buildTimeline(args) {
  const ctx = makeContext(args);
  ctx.initWorld({ night: 0, jitter: 0.35, particles: 0.14 }); // night 0 = Lumademy blue stage
  for (const scene of SCENES) await scene(ctx);
  return ctx.finish();
}
```

**A scene file** — `export default function name(ctx) { … }` (may be `async`):
```js
import { q } from '../lib/core.js';
import { maskedWords } from '../lib/recipes/kinetic-type.js';

export default function hook(ctx) {
  const { tl, w, cue, flash, show, add, wordsOut } = ctx;
  const [start, end] = ctx.range('hook');
  const s = add(`<div class="scene s-hook"><h1 class="h-title en">Make videos with one prompt</h1></div>`);
  show(s, start, end);                          // visible only during its segment
  flash(start, 0.7, 0.4); cue(start, 'impact', 1); // full energy on frame 0
  maskedWords(ctx, q(s, '.h-title'), 'hook', 0); // word i appears on spoken word i
  wordsOut(s, end - 0.3);                        // leave before the next scene
}
```
**public/css/scenes.css** — position everything in stage pixels:
```css
.s-hook .h-title { position: absolute; left: 160px; right: 160px; top: 380px; text-align: center; font: 800 120px/1.05 var(--font-display); letter-spacing: -0.03em; text-wrap: balance; }
```
`.scene` is already `position:absolute; inset:0; color:#fff; visibility:hidden`. Classes `.en` / `.bn` / `.mono`
pick Inter / Anek Bangla / JetBrains Mono. CSS variables: `--sky --blue --royal --deep --off --ice --grad` and the
brand.json colours.

**project.json** — already exists: `{ title, aspect: "16:9"|"9:16", fps: 60, tail: 2.4 }`. `tail` = seconds after
the last word (default 2.4 with a voice, 0 with a timeline). Optional `features: { particles, logo3d, bloom }` (all
default true; turn off what you don't use). Optional `timeline: [{ id, duration }]` = the time base for a video
without a voice (used when there is no `public/audio/timing.json`). script.json is only needed for a voice.

## 4. `ctx` reference

| Member | Meaning |
|---|---|
| `tl` | master GSAP timeline (paused). `tl.fromTo(node, from, to, time)`, `tl.to(…)`, `tl.set(…)` |
| `w(id, i)` / `wEnd(id, i)` | start / end time (s) of word `i` of segment `id` |
| `range(id)` / `S[id]` | `[start, end]` of the scene / the segment `{ start, end, words: [{w, start, end}] }` |
| `END`, `W`, `H` | total length (s), stage width/height (px) |
| `add(html)` → node, `show(node, from, to)` | create DOM in `#scenes`; toggle its `visibility` |
| `wordIn(span, t)`, `reveal(spans, id, offset)`, `wordsOut(node, t)` | masked word reveal on a time / on spoken words / exit |
| `flash(t, peak=0.85, dur=0.45)`, `shake(t, amount=1, dur=0.45)` | white flash; camera + scene shake |
| `at(id, s)` | `s` seconds into segment `id` (works with and without a voice) |
| `cue(t, type, gain)` | sound effect: `impact whoosh pop tick click riser shimmer glitch`, or a name from `sound()`; gain 0–1 |
| `sound(name, fn(audioCtx, dest, t, gain))` | register your own WebAudio sound (deterministic), then `cue(t, name)` — `read_guide("sound")` |
| `cueFile(t, url, { gain, offset })` | play an audio file (music, a recorded sting) from `t`; mixed into renders too |
| `onFrame(fn(t))` | per-frame hook — deterministic code only |
| `setStage(t, 'white'\|'blue', dur=0.5)` | switch the stage at `t`: white (and no vignette) or the brand-blue gradient |
| `BG.uNight`, `BG.uWarm` | other background uniforms (deep-blue night, brighter glow) — tween with `tl.to(ctx.BG.uWarm, { value: 1 }, t)` |
| `P` / `st` | particle uniforms / camera+logo state (use the particles + logo3d recipes) |
| `brand`, `project` | parsed brand.json / project.json (`brand.logo.lockup`, `brand.logo.icon`) |
| `initWorld(opts)` | once, in index.js: starting world state |

## 5. `lib/core.js`

`el(html)`, `q(node, sel)`, `qa(node, sel)`, `splitWords(node)` → `.wi` spans (Bengali-safe), `splitChars(node)`
(**Latin only**), `rand(i, k)` (deterministic 0–1), `bnNum(12)` → `১২`, `withCommas(n)`, `clamp`, `lerp`,
`icons` (arrow, play, pause, spark, person, clock, star, pin, camera, brief, check, lens). For any other icon use
Phosphor: `read_guide("assets")`.
